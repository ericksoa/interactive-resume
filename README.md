# Interactive Resume

This project is an interactive portfolio for Aaron Erickson. It provides a simple HTML, CSS, and JavaScript site that showcases career highlights and allows filtering by category.

To explore the timeline locally you need to serve the files over HTTP so the
browser can load the JSON data. The easiest way is to use Python:

```bash
python3 -m http.server
```

Then open `http://localhost:8000` in your browser.

The page lets you filter events by category and search by keywords.
